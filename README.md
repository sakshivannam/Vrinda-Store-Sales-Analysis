# Vrinda Store Sales Analysis | Microsoft Excel

## Project Overview
This project focuses on analyzing Vrinda Store's sales and order data using Microsoft Excel to understand business performance and customer purchasing behaviour.

## Business Problem
Vrinda Store wants to understand its sales performance, customer behaviour, and sales trends to identify opportunities for business improvement.

## Project Objectives
- Analyze monthly sales and order trends.
- Understand customer purchasing behaviour.
- Identify top-performing states and sales channels.
- Analyze order status and customer demographics.

## Tools & Techniques
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Data Visualization
- Interactive Slicers
- Dashboard Creation

## Key Areas of Analysis
- Monthly Sales vs Orders
- Men vs Women Sales Analysis
- Top 5 States by Sales
- Sales Channel Performance
- Age Group vs Gender Analysis
- Order Status Analysis

## Key Insights
- Women contributed 64% of total sales.
- Amazon accounted for 35% of orders.
- Maharashtra recorded the highest sales among the top 5 states.
- 92% of orders were successfully delivered.

## Learning Outcome
Gained practical experience in data analysis, dashboard creation, data visualization, and identifying meaningful business insights using Excel.
